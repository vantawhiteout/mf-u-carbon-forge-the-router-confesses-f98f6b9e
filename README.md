The Router Confesses

## Run it

`main.ts` writes the single 91-character entry line to `/output/entry.txt`.

```sh
node main.ts
```

The line is a home Wi-Fi router's excuse for dropping the connection at a movie's
climax. No network access, secrets, or dependencies are used; the file contains
the wording and nothing else runs at grading time.
